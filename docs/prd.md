## 1. 摘要

TuneTutor（仓库 `note-slice`，包名 `tune-tutor`）是一款网页版乐谱练习播放器（PWA）：用户加载 MusicXML 乐谱，浏览器内渲染五线谱，通过**单击选小节、双击选乐句**圈定练习范围，以**可调速度（40–240 BPM）**、**7 种乐器采样音色**和**可定制节拍器**进行循环跟练；特有的「空拍循环」在每轮循环之间留出 1–8 拍静音间隔，训练节奏反应。配套「原曲」页支持导入音频（mp3/wav/ogg/m4a），在波形上拖选片段做同样的带空拍循环，用于对照原曲扒谱练习。

## 3. 背景

乐器初学者练习一首新曲时的典型流程是「看谱 → 慢速跟弹 → 对卡壳的乐句反复抠细节」。现有工具链要么是纸质谱（不能发声、速度不可调），要么是昂贵的制谱软件（Sibelius / Finale），要么是通用 DAW（为乐谱循环做标记操作繁琐）。浏览器已具备高质量音频采样调度（Web Audio / Tone.js）与成熟的乐谱渲染能力（OSMD），使得一个**零安装、本地存储、免费**的练习工具成为可能。

项目演进脉络（据 git 历史）：

1. 早期：VexFlow 自渲染原型（旧版 spec 所述架构，见 git 历史，现已过时）；
2. `4dbf604`：迁移到 OpenSheetMusicDisplay（OSMD）渲染；
3. `c58fe03`：加入循环跳过、节拍器，播放控制拆分组件；
4. `6d55e31`：双击选择乐句循环；
5. `022af42`：统一播放时间轴（由 OSMD 光标派生）；
6. `666183c`：新增「原曲」音频切片循环页（wavesurfer.js），路由化为多页面；
7. 2026-10-17：删除全部旧实现，按 [tech.md](./tech.md) v2 重写（进行中，见文首现状注）；同日完成本文 v1.1 功能完整性核查（audio.md / selection.md 拆分成文后首次对齐）。

## 4. 目标

**目标**：让任何乐器学习者打开网页即能开始有效率的分段练习——5 秒内恢复上次乐谱，10 秒内开始对任意乐句做变速循环。

**为什么重要**：练习效率的核心是「快速圈定难点 + 慢速重复 + 逐步提速」，这正是本产品全部功能围绕的主线。

**关键结果（KR，SMART 形式）**：

- KR1：页面加载后自动恢复最近一次打开的乐谱（无历史时回落到内置示范曲《小星星》），恢复成功率 100%（IndexedDB 可用时）。
- KR2：建立一次乐句循环所需的用户操作 ≤ 2 次双击；建立一次空拍循环 ≤ 2 次点击。
- KR3：全部用户可见文案覆盖 4 种语言（en-US / zh-CN / zh-TW / fr-FR），由 `tests/locales/index.test.ts` 强制校验。
- KR4：PWA 可安装、可离线访问（GitHub Pages 部署，scope `/TuneTutor/`）。

## 5. 市场细分

按「要完成的任务」而非人口属性划分：

| 细分 | 任务（Job） | 关键诉求 | 约束 |
| --- | --- | --- | --- |
| 乐器初学者 / 琴童 | 慢速跟谱视奏 | 低至 40 BPM 的慢放、节拍器、光标跟随 | 免费、免安装、家长可代为准备乐谱文件 |
| 进阶自学者 / 扒谱者 | 对照原曲抠细节 | 原曲音频切片循环、空拍留白反应训练 | 音频本地处理，不上传服务器 |
| 音乐教师 | 课堂片段示范 | 快速加载任意 MusicXML、乐句循环展示 | 浏览器即开即用，无需账号 |

通用约束：桌面浏览器优先（移动端布局可用但未专门优化，触控专项 = G12）；所有数据存本地（IndexedDB + localStorage），无后端、无账号体系。

## 6. 价值主张

**客户任务**：把「看谱 → 圈定难点 → 慢速重复 → 提速」的练习循环搬进浏览器。

**客户获得**：

- 零安装、零费用的乐谱播放器（对比商业制谱软件）；
- 乐句级精确定位循环（对比「整曲重放」的通用播放器）；
- 7 种乐器采样音色替换试听（钢琴 / 萨克斯 / 吉他 / 贝斯 / 小提琴 / 长笛 / 小号）；
- 独创性的**空拍循环**：每轮循环之间插入 1–8 拍静音，迫使用户在间隔中预唱 / 预奏下一轮，训练内在节奏感；
- 原曲音频 + 乐谱双轨练习：同一速度值在两页间共享，空拍换算一致。

**避免的痛点**：无需购买软件、无需导入 DAW 做标记、无需翻纸质谱倒带。

**差异化（价值曲线）**：同类开源工具普遍缺少「空拍循环 + 双击选乐句 + 原曲波形切片」三者组合；本产品以练习科学性（间隔重复）而非制谱功能取胜。主线闭环对照：圈定难点 = F4/F14，慢速重复 = F6/F7，逐步提速 = F6 手动拖杆（G3 渐快循环将其自动化——这是当前主线最大的功能缺口，见 §7.2.2）。

## 7. 解决方案

### 7.1 UX / 原型

整体为单应用双页面结构（`react-router-dom` **HashRouter**，兼容 GitHub Pages 静态托管）：

```
App（Header 导航 + 共享速度值 tempo）
├── 「乐谱」ScorePage（/）
│   ├── 页工具栏：乐器选择器 + 加载文件按钮
│   ├── ScoreInfo：曲名 / 作曲 / 拍号 / 原速
│   ├── 五线谱卡片（OSMD 渲染 + 选择覆盖层）
│   ├── SelectionInfo：当前选择范围 + 清除
│   ├── PlaybackControls（吸底）：速度滑杆 │ 走带按钮 │ 节拍器 │ 循环跳过
│   ├── StatusBar（深色页脚）：选择 / 速度 / 乐器 / 循环状态
│   └── FileLoaderModal（弹窗）：拖放上传 + 最近文件
└── 「原曲」OriginalAudioPage（/audio）
    └── 波形卡片：导入区（空态）→ 波形 + 拖选切片 → 走带 + 空拍
```

关键交互流：

- **加载乐谱**：工具栏「加载文件」→ 弹窗内拖放 / 点选 `.musicxml` / `.xml` → 解析渲染；或从「最近文件」历史直接打开（存于 IndexedDB）。
- **选择模型**（优先级从高到低，细则见 [selection.md](./selection.md)）：
  1. **乐句循环**：双击起始音符（pending 弱高亮）→ 再双击结束音符（原生 `dblclick`；顺序颠倒自动换位）→ 显示朱砂色 START `|▶` / END `◀|` 括号标记与箭头（视觉基线 v3 两端同色，仅箭头方向区分）+ 音符高亮 + 范围条 → 播放时仅循环该范围；
  2. **单击选择**：单击音符**即时**选中其所在小节（零延迟，无双击检测窗口），选择信息显示「第 x–y 小节 (n 个音符)」，配合空拍设置时循环该区间；乐句起点的 pending 意图由 500ms 延迟销毁窗口保护，不被双击第二击的单击吞掉；
  3. **无选择**：空拍 > 0 时循环全曲，否则顺序播放至结束自动停止。
- **清除与播放中改选**：Esc / 清除按钮清零全部选择；播放中改变选择允许，下一轮循环边界生效（不热改运行中的调度）。
- **空拍循环（跳过拍）**：点击 1–8 中的数字设定间隔拍数，再次点击当前值归零；间隔以当前 BPM 现算秒数，随速度联动。
- **节拍器**：主按钮开关；齿轮弹出设置面板（音色四选一：经典 / 电子 / 底鼓 / 敲击；强拍、弱拍音量滑杆），点击面板外或 Esc 关闭。
- **键盘快捷键**：`Space` 播放 / 停止切换；`Esc` 停止（输入框聚焦时忽略）。
- **原曲页**：空态为虚线导入区（拖放或点选音频）；加载后在波形上拖出朱砂色切片区域（可拖动 / 边界微调，双击区域移除）；播放键循环切片，「空拍」0–8 拍设定轮间静音；切至后台标签页自动暂停循环；「移除」删除音频与切片。
- **页面切换**：离开乐谱页自动停止播放；速度值在两页间共享（乐谱页可改，原曲页只读，原曲页空拍换算用同一 BPM）。

高保真页面示意、组件状态与设计规范见配套 [ui-design.html](./ui-design.html)（v3「纸墨排练室」：米纸暖底 + 白玉卡面，墨色交互主色、朱砂练习循环语义色、金铜播放态；四个标签页：乐谱练习页、加载乐谱弹窗、原曲练习页、设计规范）。

### 7.3 技术

React 19 + TypeScript（strict，`verbatimModuleSyntax` / `erasableSyntaxOnly`）+ Vite 7 + Tailwind CSS 4；OSMD ^1.9 渲染乐谱；`musicxml-io` 解析（`fs/promises` 浏览器垫片）+ `jszip`（`.mxl` 解包）；Tone.js ^15 Sampler 采样触发；播放引擎 look-ahead 窗口调度（官方播放器同构；播放数据唯一来源 = OSMD 光标，乐谱时域，BPM 变更即时重锚定）；wavesurfer.js ^7.12（Regions 插件）波形切片；`react-router-dom` HashRouter 路由；vitest 单测（换算 / 播放数据 / 时钟 / 切片纯函数、存储、i18n 完整性）。构建与部署硬约束见 `AGENTS.md` 与 [tech.md](./tech.md) §9。

### 7.4 假设与已知限制

**假设（待验证）**：

- A1：用户能自行获得 MusicXML 文件（本产品不提供乐谱资源）；
- A2：空拍循环的练习价值（间隔重复训练）被目标用户感知为差异化功能；
- A3：本地存储（无云同步）满足单人单设备使用场景。

**已知限制（如实记录；L 编号跨文档引用，保持稳定）**：
