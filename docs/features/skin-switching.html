01色彩 Token 全表（9 皮肤 × 34 token）

与 src/index.css 的 Tailwind v4 @theme 命名一一对应；带 ★ 为皮肤化需新增的 token。实现时默认值置于 :root（= paper），其余皮肤置于 :root[data-theme=<id>] 覆盖块。

Token用途 纸墨paper 夜曲nocturne 暖木walnut 青瓷celadon 演奏会stage 青花cobalt 宫墙palace 红木rosewood 玄漆lacquer

阴影与几何：圆角、字体、间距全皮肤共享；三组阴影（shadow-soft / pop / paper）按皮肤换基调——浅色皮肤沿用暖棕投影 + 白色内高光，深色皮肤改纯黑投影（alpha 0.55–0.8）+ 极弱内高光，具体值随皮肤块定义（本页 JS 内 SKINS 数据即为准值）。

02新增 Token（★ 7 项）

现有组件中的写死颜色提升为 token，皮肤才能整体换色。

--color-header页头半透明底。页头浮于画布之上，各皮肤需要独立的半透明面（现写死 rgb(255 253 247/0.55)）。
--color-ink-hover主按钮悬停色。深色皮肤 ink 为浅色，悬停需向更亮走而非更深。
--color-track滑杆轨道底（现写死墨色 14%，深色皮肤下不可见）。
--color-wash墨色水洗底：空态占位、图标底、极浅强调面（现写死 rgb(36 31 21/0.02)）。
--color-wave-bg波形区底色（现写死 #f3efe2）。
--color-wave-bar-a / -b波形条渐变双端（现写死 #b9ae8d → #948a60）。
派生色用 color-mix光晕、遮罩、半透明叠加一律 color-mix(in srgb, token n%, transparent) 派生，不新增 token。

02存储与首帧

localStorage 键 note-slice-theme（对齐 note-slice-language 命名），合法值 paper | nocturne | walnut | celadon | stage | cobalt | palace | rosewood | lacquer，缺省 paper；非法值回退默认。首帧防闪白：index.html <head> 内联脚本先于样式应用：

<!-- index.html，置于 <head> 内联 -->
<script>try { var t = localStorage.getItem('note-slice-theme');
  if (t) document.documentElement.dataset.theme = t; } catch (e) {}</script>

换肤实现：useTheme() hook 写 document.documentElement.dataset.theme + localStorage；不引入 context 重渲染（token 级联由 CSS 完成，React 状态仅用于切换器 UI 的选中态）。

04乐谱域契约（OSMD）

取色OSMD 集成落地时（tech §6.1），EngravingRules 颜色一律读 token：谱线 staff、小节线 barline、符干/符头/文字 ink、辅助文字 ink-2；纸面底色由乐谱卡 CSS（--color-paper）承担，OSMD 保持透明背景。
换肤时机皮肤切换触发 osmd.render() 重建 + 选择/乐句覆盖层按既有 graphicIndex 重建；切换为低频显式操作，一次性重排可接受，不做过渡动画。
光标与语义播放光标 gold-bright（含 color-mix 光晕）；选中符头/括号 verm；深纸面皮肤（夜曲/玄漆/演奏会）符头自动转浅色（ink 在该皮肤为浅色值），无需单独「夜间谱面」分支。
宫墙特例练习语义为石绿，选中符头/括号/标签随之转绿；角色分配不变（仍是「练习循环」这一语义角色），不产生第二种选中色。

05决策记录 T1–T10

#决策
T1承载方式：全部颜色走 CSS 自定义属性（Tailwind v4 @theme 即自定义属性，可直接被更高优先级选择器覆盖）；皮肤 = :root[data-theme] 重定义 token，组件零改动、不写死色值。
T2语义角色分配跨皮肤不变（哪类元素用哪个角色）；角色色相允许随皮肤整体重定，同一皮肤内全站一致。例：宫墙练习语义转石绿（青绿对朱砂的传统配色）、青花交互主色转钴青。
T39 款默认皮肤，id 固定：paper / nocturne / walnut / celadon / stage / cobalt / palace / rosewood / lacquer。不做「跟随系统」——明暗已由夜曲/玄漆/演奏会手动覆盖，避免组合爆炸；新增皮肤走同一 token 契约。
T4存储 localStorage「note-slice-theme」，缺省 paper，非法值回退；index.html 首帧内联脚本写 data-theme 防闪白（FOUC）。
T5入口：页头弹层（复刻 LangSwitcher 交互与 a11y 范式），分组「经典 / 古风」；不设独立设置页。
T6OSMD：EngravingRules 读 token，换肤触发重渲染（见 04 节契约）；乐谱纸面底色走 CSS 不走 OSMD。
T7换肤过渡 160ms ease（对齐 v3 动效基准），OSMD 重渲染不动画；prefers-reduced-motion 全瞬时。
T8无障碍底线：正文对所在面 ≥ 4.5:1；「演奏会」对标 WCAG AAA（正文 ≥ 7:1）作高对比选项；语义色光晕/淡底仅作装饰不作唯一信息载体。
T9古风四款取材传统工艺：青花（青花瓷：瓷白纸面、钴青交互、釉里红练习、泥金播放）；宫墙（宫墙红+金瓦：漆黑交互、石绿练习、金系播放与进行中指示）；红木（酸枝家具：深棕红画布、绢黄纸面、黄铜播放、靛蓝练习——蓝染对植木，与宫墙的红墙绿语义区分）；玄漆（黑漆描金：暖黑底、漆白交互、描金播放、朱砂练习）。token 名保留 verm/gold 历史角色名，值随皮肤走、类名不变。
T10图标双层主题化（以 brand.html 为先决基准）：功能图标统一内联 SVG、stroke=currentColor，只换色不换形，随 token 自动跟随。全量替换清单与 SVG 路径规格见 ①-02（乐器 7 枚专形专绘、bass/guitar 分化；节拍器以塔形摆锤取代 🥁 鼓形；走带 play/stop 实心；loop/gear/folder/note/trash/phones/palette 各归其位）；品牌标（反复记号）几何恒定、零皮肤配置——瓦片底 = ink token、标记描色 = cream token（currentColor，三部件同色），由 CSS 级联自动跟随换肤；语义色禁止上品牌标、不做字形/形制变体；favicon 与 PWA 图标不随皮肤（构建期静态生成）。
