06品牌标志

标志「反复记号」：一粗一细两道界线加右侧两点——正是产品的核心动作，框一段乐句，来回练。纯墨单色两值（墨 #241F15 / 米白 #F8F3E7），靠粗线 / 发丝线 / 实点立形体，不依赖渐变与第二色。应用内品牌位固定用「墨底米白标」圆角方块（见各页页眉与 PWA 图标），浅色底 / 印刷场景用墨色标；不要给标志加投影、描边或换色。构成比例、变体清单、尺寸下限与安全区以 docs/brand.html（视觉资产基准）为准，矢量源文件在 docs/brand/。

标志用法
左：墨底米白标（应用内品牌位 / 应用图标）；右：浅底墨标（印刷、浅色背景）
