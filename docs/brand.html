TuneTutor · 品牌规范 v1 · 2026-10-18

反复记号

标志取自谱面上的反复记号：一粗一细两道界线，右侧两点。产品的核心动作就是它——框一段乐句，来回练，加空拍，再回来。整套为纯墨单色，靠粗线 / 发丝线 / 实点三种笔画立形体，不依赖渐变、透明或第二色。

01

两种基本形态

横版锁标 · 标志与字标同高对齐，间距 16（相对标记高 44）。用于页头、README 首屏、文档封面。
独立标记 · 64 盒内高 48、宽 35.8。用于应用图标、favicon、窄位（移动端页头）。
02

构成与比例

粗线宽 8，是整套的"重音"
间距 17.6
发丝线宽 2.6 —— 与粗线的 3:1 对比是这套标志的全部张力所在
间距 27.2
圆点直径 10.4，圆心落在竖线高度的 1/3 与 2/3 处
整体高 48 × 宽 35.8，宽高比 0.746

以上数字以 64 单位盒为基准，任何放大缩小都按同一比例因子等比换算——这三个数（8 / 2.6 / 10.4）是标志的身份，改任一个都会垮掉粗细节奏。

实测（resvg 光栅化后目视）：标记 32px 起发丝线清晰；24px 需换 small 版；16px 只建议用在带底色瓦片里做 favicon，裸标记在 16px 会糊。横版锁标总高不低于 36px——低于此值字标 cap 高不足 16px，请改用独立标记 + 界面活字。数字是观察结论，不是普适标准。

05

安全区

四周留白 不小于一个圆点的直径（标记高度的 0.217×；64 盒内即 10.4 单位）。

虚线内圈是"绝对不可侵占"的边界，外圈是建议留白。标志旁边出现按钮、分割线、图片边缘时，先保证这条边距。

07

不要这样做

拉伸只能等比缩放。拉宽会让粗线与发丝线的 3:1 关系失真。
旋转它是谱面上的竖直界线，倾斜就不再是记号。
投影 / 描边 / 发光纯墨单色是它的立身之本。
低对比底色只放在 canvas / surface / cream 或 ink 上，别放在中间明度。
换掉圆点的颜色三个部件同色。这一点被改，标志立刻变成别的品牌的配色。
TuneTutor
用系统字体重排字标横版锁标里的字标已是轮廓路径，直接引用 SVG，别用 font-family 重排。

09

复现说明

  • 标记在 64 单位盒内由 rect + circle 组成，无路径、无变换矩阵、无渐变、无滤镜、无外部引用——任何 SVG 工具都能无损编辑。
  • 横版锁标的字标由 fontTools 从 EB Garamond Bold 700 提取轮廓，字号 40、字距 0.014em、基线 y=43.56，合并为单条 path。
  • PNG 阶梯由 resvg 直接光栅化 SVG 得到（16/32 取 small 版），未做位图二次处理。
  • 交付前静态自检：XML 可解析、无 %% 格式化残留、无 <image>/base64/外部 href、每个文件都有 viewBox——全部通过。

这是一份视觉自检记录，不是商标检索结论，也不构成"可注册"或"无冲突"的判断。
